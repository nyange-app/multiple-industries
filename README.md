# multiple-industries

Static [Astro](https://astro.build) site (Tailwind v4, MDX, sitemap), same stack and layout as `nyange-site`.

```bash
pnpm install
pnpm dev
pnpm build
```

Requires Node 22 (`.nvmrc`) and pnpm 8.

## Layout

- `src/` — pages, layouts, components, styles, `config.ts` (site constants)
- `public/` — static assets
- `infra/` — Terragrunt/Terraform (placeholder)
- `.github/workflows/` — CI/deploy (placeholder)
- `docs/design/` — design notes
